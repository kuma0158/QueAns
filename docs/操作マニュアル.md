# 社内Q&Aシステム「QueAns」操作マニュアル

最終更新: 2026-06-01
対象システム: 社内Q&A管理システム QueAns（`https://que-ans-eight.vercel.app/`）

---

## 1. はじめに

QueAns（キューアンス）は、社内の質問（確認事項）と回答を一元管理するためのシステムです。
「プロジェクト」ごとに質問をぶら下げて管理し、起票日・期限・回答者・ステータス・添付ファイルまでまとめて記録できます。期限超過の自動判定やダッシュボードでの進捗集計も行えます。

### 1.1 用語

| 用語 | 意味 |
|------|------|
| **プロジェクト** | 質問をまとめる単位（研修・案件・テーマなど）。 |
| **質問（確認事項）** | 1件1件の問い合わせ。回答・期限・担当者などを持ちます。 |
| **カテゴリー** | 質問に付ける分類タグ。色付きで、1質問に複数付けられます（多対多）。 |
| **ステータス** | 質問の進行状態（新規／対応中／完了、および自動判定の期限超過）。 |

### 1.2 動作環境
- 推奨ブラウザ: Google Chrome / Microsoft Edge / Firefox の最新版
- 通信は HTTPS で暗号化されています。

### 1.3 権限（ロール）
ログインユーザーには「管理者」「一般」の区別があり、画面右上に表示されます。本システムでは、ログインすればどちらの権限でも質問・プロジェクト・カテゴリーの閲覧・登録・編集が行えます。

## 2. ログイン・ログアウト

### 2.1 ログイン
1. ブラウザで `https://que-ans-eight.vercel.app/login` を開きます。
2. 「QueAns ログイン」画面で、次を入力します。
   - **ユーザー名**: `user`
   - **パスワード**: `user9090`
3. **「ログイン」** ボタンをクリックします。
4. 成功するとプロジェクト一覧（トップ画面）へ移動します。

> ユーザー名またはパスワードが違う場合、「ユーザー名またはパスワードが違います」と赤字で表示されます。入力内容を確認してください。

### 2.2 ログアウト
画面右上の **「ログアウト」** ボタンをクリックします。ログイン画面に戻れば完了です。共有PCでは必ずログアウトしてください。

> ログインしていない状態で各ページを開こうとすると、自動的にログイン画面へ誘導されます。

---

## 3. 画面の基本構成

ログイン後はすべての画面の上部に共通ヘッダーが表示されます。

- **QueAns（ロゴ）**: クリックでトップ（プロジェクト一覧）へ。
- **ナビゲーションタブ**:
  - **プロジェクト** … プロジェクト一覧／管理（トップ画面）
  - **ダッシュボード** … 全体の集計・進捗
  - **カテゴリー管理** … 分類タグの登録・編集
- **右上**: ログイン中のユーザー名・権限（管理者／一般）・ログアウトボタン

---

## 4. プロジェクト

### 4.1 プロジェクト一覧（トップ画面）
ヘッダーの **「プロジェクト」** またはロゴをクリックします。

- 登録済みプロジェクトがカード形式で並びます。各カードに以下を表示:
  - プロジェクト名・説明・質問の総件数
  - **進捗バー**（完了した質問の割合）と進捗％
  - **未完了** 件数、**超過**（期限超過）件数
- カードをクリックすると、そのプロジェクトの **質問一覧** へ移動します。

### 4.2 プロジェクトの作成
トップ画面下部の **「プロジェクト管理」→「新規プロジェクト」** フォームを使います。
1. **プロジェクト名**（必須）を入力。
2. **説明**（任意）を入力。
3. **表示順**（数字。小さいほど上に表示。初期値は自動採番）を必要に応じて調整。
4. **「追加」** をクリック。

### 4.3 プロジェクトの編集・削除
「プロジェクト管理」の一覧表で操作します。
- **編集**: 行の **「編集」** をクリック → 名前・説明・表示順を修正 → **「保存」**。
- **削除**: 行の **「削除」** をクリック → 確認ダイアログで **OK**。
  - **注意**: 質問が1件でも紐づいているプロジェクトは削除できません。先に質問をすべて削除してください。

---

## 5. 質問（確認事項）

### 5.1 質問一覧（プロジェクト内）
プロジェクトのカードをクリックすると表示されます。質問が一覧表で並びます。

表示列: # / カテゴリー / 確認事項 / 質問者 / 起票日 / 期限 / 回答者 / ステータス / 編集

- **確認事項**（タイトル）をクリックすると質問の **詳細画面** へ。
- **期限超過** の行は期限が赤字・太字で強調されます。
- 右端の **「編集」** から直接編集画面へ移動できます。

#### ステータスの種類
| 表示 | 意味 |
|------|------|
| **新規** | 登録直後、未着手。 |
| **対応中** | 対応を進めている状態。 |
| **完了** | 回答が確定し対応が終わった状態。 |
| **期限超過** | 完了していない質問で期限日を過ぎたもの（**自動判定**）。 |

### 5.2 質問の検索・絞り込み
一覧上部のフィルターで絞り込めます。
- **ステータス**: すべて／新規／対応中／完了／期限超過 のボタンで切り替え。
- **カテゴリー**: すべて／各カテゴリー／未分類 のボタンで切り替え。
- **キーワード検索**: 右側の入力欄に語句を入れて **「検索」**。確認事項の内容・質問者・回答者を対象に部分一致で検索します。

> 絞り込み条件はURLに反映されるため、その状態のままブラウザのブックマークや共有が可能です。

### 5.3 質問の閲覧（詳細画面）
一覧で確認事項をクリックすると表示されます。
- ヘッダー: 質問番号・プロジェクト名・ステータス・カテゴリー・起票日・期限・質問者・回答者
- **Q 確認事項**: 質問本文
- **A 回答**: 回答本文（未入力の場合は「未回答」）
- **備考**: 入力があれば表示
- **添付ファイル**: 画像はサムネイル表示、その他はファイル名リンク（クリックで開く/ダウンロード）
- 右上の **「編集する」** で編集画面へ。

### 5.4 質問の新規投稿
方法は2通りあります。
- プロジェクト質問一覧の右上 **「+ 新規質問」**（そのプロジェクトが初期選択されます）
- ※直接URL `…/questions/new` から開くことも可能

入力項目:

| 項目 | 必須 | 説明 |
|------|:---:|------|
| **プロジェクト** | ● | どのプロジェクトの質問か選択。 |
| **質問者** | ● | 質問した人の氏名。 |
| **カテゴリー** | | 該当するタグをクリックで複数選択。 |
| **確認事項** | ● | 質問の本文。 |
| **期限** | ● | 対応期限（日付）。初期値は3日後。 |
| **回答者** | | 回答担当者の氏名。 |
| **ステータス** | | 新規／対応中／完了。初期は「新規」。 |
| **回答** | | 回答本文。 |
| **備考** | | 補足メモ。 |

入力後 **「登録」** をクリックすると保存され、対象プロジェクトの一覧へ戻ります。
中止する場合は **「キャンセル」**。

### 5.5 質問の編集・削除
質問詳細または一覧の **「編集」** から編集画面を開きます。
- 内容を修正して **「更新」** で保存。
- 画面左下の **「削除」** で質問を削除（確認ダイアログで **OK**）。

### 5.6 添付ファイル
添付ファイルの追加・削除は **質問の編集画面** で行います（画面下部「添付ファイル」欄）。
1. **「+ ファイル追加」** をクリックしてファイルを選択（複数選択可）。
2. アップロードが完了すると一覧に追加されます。
   - 画像（PNG / JPG / GIF / WebP 等）はサムネイル表示。
   - その他のファイルは 📎 アイコン＋ファイル名・種類・サイズで表示。
3. ファイル名リンクをクリックすると別タブで開けます。
4. 削除する場合は各ファイルの **「削除」** → 確認ダイアログで **OK**。

> **制限**: 1ファイルあたり最大 **10MB** です。

## 6. ダッシュボード

ヘッダーの **「ダッシュボード」** をクリックします。全プロジェクト横断の集計が表示されます。

- **件数サマリー**: 全件数／新規／対応中／完了／期限超過 の5指標。
- **進捗率**: 完了件数 ÷ 全件数（％）と進捗バー。
- **プロジェクト別 件数**: 棒グラフ。名前クリックでそのプロジェクトへ移動。
- **カテゴリー別 件数**: カテゴリーごとの質問数（色付き棒グラフ）。
- **期限超過（未完了）**: 期限超過の質問を最大10件、期限が近い順に表示。クリックで詳細へ。

---

## 7. カテゴリー管理

ヘッダーの **「カテゴリー管理」** をクリックします。質問に付ける分類タグを管理します。

### 7.1 カテゴリーの作成
「新規カテゴリー」フォームで入力します。
1. **カテゴリー名**（必須）。
2. **色**: 9色のプリセットから選択（質問一覧やバッジで使われます）。
3. **表示順**: 数字（小さいほど上）。
4. **「追加」** をクリック。

### 7.2 カテゴリーの編集・削除
一覧表で操作します。
- **編集**: 行の **「編集」** → 名前・色・表示順を修正 → **「保存」**。
- **削除**: 行の **「削除」** → 確認ダイアログで **OK**。
  - そのカテゴリーが質問に使われている場合、「○件の質問が『未分類』になります」と表示されます。削除しても質問自体は残り、分類だけが外れます。

## 8. よくある質問・トラブルシュート

| 症状 | 対処 |
|------|------|
| ログインできない | ユーザー名・パスワードを再確認。解決しなければ管理者に確認。 |
| 質問が一覧に出てこない | ステータス／カテゴリーのフィルターが絞り込まれていないか確認。「すべて」に戻すと全件表示。検索キーワードもクリア。 |
| 期限を過ぎていないのに「期限超過」になる | 期限は日付単位で判定されます。期限日を過ぎ、かつ未完了の質問が対象です。完了にすると外れます。 |
| プロジェクトが削除できない | 質問が紐づいています。先に質問をすべて削除してください。 |
| 添付ファイルがアップロードできない | ファイルサイズが10MBを超えていないか確認してください。 |
| しばらく操作後に動作が重い／反映が遅い | サーバーのコールドスタートの可能性があります。少し待って再読み込みしてください。 |
